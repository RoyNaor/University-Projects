# 🎓 University Projects

Welcome to the **University Projects** repository! This collection showcases various coding exercises and assignments completed during my university studies, spanning multiple programming languages and computer science topics.

---

## 📁 Repository Structure

The repository is organized into directories based on programming languages and subjects:

- **C/**: Projects and exercises written in the C programming language.
- **C++/**: Implementations and assignments using C++.
- **Java/**: Java-based projects covering various concepts.
- **Python/**: Scripts and programs developed in Python.
- **OOP/**: Object-Oriented Programming assignments and examples.
- **OS/**: Operating Systems related projects and exercises.

---

## 🧠 Topics Covered

- **Data Structures**: Implementation of linked lists, trees, graphs, and more.
- **Algorithms**: Sorting, searching, and algorithmic problem-solving.
- **Object-Oriented Programming**: Principles and applications in Java and C++.
- **Operating Systems**: Process management, memory allocation, and system calls.
- **File I/O**: Reading from and writing to files in various formats.
- **Multithreading**: Concurrent programming and thread management.

---

## 🚀 Getting Started

To explore the projects:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/RoyNaor/University-Projects.git
   ```

2. **Navigate to a project directory**:
   ```bash
   cd University-Projects/Java/ProjectName
   ```

3. **Follow the specific instructions** in the project's README or comments to build and run the code.
